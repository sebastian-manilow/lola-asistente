# Contribuir
1. Abre un issue describiendo el cambio o fallo.
2. Haz fork, rama corta y commits pequeños y claros.
3. Comprueba que compila: `python -m py_compile voz/escucha.py voz/hablar.py`.
4. No incluyas datos personales, claves ni audio. Respeta `SEGURIDAD.md`.
5. Abre un pull request con una descripción breve.
